# Sandeep Kanathil Aji — GitHub Pages Portfolio

Ready-to-upload static website.

## Publish on the correct GitHub account

1. Sign in at https://github.com/sandeep9009 (Sandeep’s own account).
2. Create a **public** repository named exactly `sandeep9009.github.io` (not `robotic`).
3. Open the repository, choose **Add file > Upload files**.
4. Unzip this archive locally; upload **all contents** of the `sandeep9009.github.io-ready` folder, including `index.html`, `presentations/`, and `.nojekyll`, to the repository root. Commit the changes. Do not upload only the ZIP.
5. Go to **Settings > Pages**, set Source to **Deploy from a branch**, Branch **main**, Folder **/(root)**, then Save. (If already set up, no changes are needed.)
6. After GitHub Pages finishes deployment, visit https://sandeep9009.github.io/

The site uses relative paths suitable for the root domain.

## What is included

- `index.html` – home page, projects, presentations and learning information.
- `presentations/` – four browser-viewable PDFs with HTML viewer pages.
- Three editable `.pptx` presentations in `presentations/files/`.
- `.nojekyll` – disables unnecessary Jekyll processing.

The IBM SkillsBuild deck is categorized as an *AI learning presentation*, not as proof of certificates owned by Sandeep. Only add credential verification if a certificate actually belongs to him.
